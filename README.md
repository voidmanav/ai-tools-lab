# AI Tools Lab

## 1. Project Description

AI Tools Lab is a Python-based project developed for a college Machine Exercise. It demonstrates basic sorting algorithms, utility functions, and fundamental Python programming concepts.

## 2. Features

* Implementation of sorting algorithms.
* Reusable utility functions.
* Simple and beginner-friendly code.
* Organized project structure.

## 3. Installation Instructions

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/your-username/ai-tools-lab.git
cd ai-tools-lab
```

Run the Python file:

```bash
python hello.py
```
